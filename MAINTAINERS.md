### Honest status note

As of 2026-06-02 this is a **single-maintainer, single-organisation project**. This is
a known gap relative to OpenSSF Incubating requirements (which require ≥ 3 maintainers
from ≥ 2 organisations). It is not a blocker for Sandbox entry but must be resolved
before applying for the Incubating stage.

We actively seek co-maintainers — see the [contributor ladder](#contributor-ladder) below.
If you are interested, open an issue or email `davidrydgren@gmail.com`.

## Contributor Ladder

| Level | Requirements | Permissions |
|-------|-------------|-------------|
| **Contributor** | At least one merged PR | Can file issues and PRs; triaged by maintainers |
| **Reviewer** | 5+ quality PRs; consistent engagement over ≥ 3 months | Can be requested as PR reviewer; listed in CODEOWNERS |
| **Maintainer** | Reviewer for ≥ 6 months; demonstrated understanding of project scope; nominated by an existing maintainer and approved by all current maintainers | Write access; can merge PRs; listed in this file |
| **Emeritus Maintainer** | Former maintainer who steps down gracefully | Retained in MAINTAINERS.md with emeritus designation |

Maintainer decisions are made by consensus. In the event of persistent disagreement,
the Project Lead has the casting vote until a governance body is established.

## OCHS Specification Stewardship

The OCHS specification (`docs/ochs/OCHS-v0.1.md`) and its JSON schema are maintained
under the same maintainer group as the reference implementation. OCHS specification
changes require at least one maintainer review plus a 14-day public comment period
before merging (except for editorial/typo fixes, which can merge immediately).
